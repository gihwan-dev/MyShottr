# MyShottr v0.1.0

The first public MyShottr release adds local macOS region capture, clean Chrome
visible-viewport capture, editable Quick Ink annotations, composited PNG
output, `.myshottr` project files, and crash recovery.

## Important installation note

Move MyShottr to `/Applications`, then use Finder's Control-click **Open**
flow. If macOS still blocks the app, use **System Settings → Privacy &
Security → Open Anyway**. Open the app once before loading the Chrome
extension so the per-user Native Messaging Host is registered.

This distribution is unsigned and unnotarized. The two executables may contain
link-time ad-hoc signatures created by the build; they have no Developer ID
identity and the release has not been reviewed or notarized by Apple. The
Chrome package is an unpacked extension, not a Chrome Web Store package.

## Known limitations

- Chrome captures only the visible viewport; full-page capture is not included.
- The extension requires Developer mode and manual **Load unpacked**
  installation.
- Desktop mockups and other presentation frames are not included.
- Safari, Firefox, OCR, capture history, and automatic updates are not included.
- Developer ID signing, Apple notarization, the Mac App Store, and the Chrome
  Web Store are not included.
